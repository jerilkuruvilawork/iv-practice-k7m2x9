Simple speaking rules

  • Talk a bit slower than normal — like giving a calm handover.
  • Bold words: slow down a tiny bit there.
  • Stop for half a second after full stops.
  • On hard honesty bits: softer voice, not sorry, not angry.
  • On leadership bits: clear and steady — “this is what I do”.
  • At the end: finish the last line, then stop. Don’t add “yeah…” or “so…”.

Likely interview task — how to think

  • Patient safety first, then protocol / visit windows
  • Prioritise: clinical emergency / SAE → stop unsafe practice → time-critical visits → screening → admin queries
  • Consent pressure: voluntary, time, PIS, delegation log, never coerce, escalate to PI
  • SAE: help patient → tell PI → criteria → timelines → document
  • If unsure: say what you’d check and who you’d ask — don’t invent protocol rules

One-liner: “Safety and valid consent first, then time-critical visits, escalate outside my competence, data queries last.”

Consent — say these points

  • Capacity / understanding
  • Approved PIS + consent form only
  • On the delegation log for that study
  • What / why / risks / benefits / options
  • Voluntary + can withdraw; care continues either way
  • Time to decide; check understanding
  • Document; escalate to PI if unsure
  • Never pressure

Patient withdraws after consent

  1. Respect immediately — no persuading, no guilt
  2. Reassure: NHS care continues as normal
  3. Thank them for considering the study
  4. Optional: gently ask why (support/learning only — not to change their mind)
  5. Explain data/samples already collected — per protocol / PIS; ask PI if unsure
  6. Stop further study procedures
  7. Tell the PI / team; update systems
  8. Document withdrawal clearly

One-liner: “They can withdraw anytime — I respect it at once, care continues, I document and tell the PI.”

Confidentiality in research

  • Why: trust, dignity, legal/professional duty (UK GDPR, Trust, NMC, protocol/PIS)
  • Share only on a need-to-know basis (care / study team)
  • Use secure systems; lock screens; no corridor gossip
  • Follow protocol on coded / anonymised data and samples
  • Explain limits in the PIS (who may see data — PI, sponsor monitors, auditors, etc.)
  • If breach/risk → escalate PI/senior + Trust incident process

One-liner: “Without confidentiality, people won’t trust research — I protect information need-to-know and escalate any breach.”

SAE — order to say

  1. Patient safety / clinical help first
  2. Tell the PI straight away
  3. Is it serious? (hospital / life-threatening / etc. per protocol)
  4. Report within protocol / Trust timelines
  5. Document clearly
  6. Follow up and learn with the team

Managing stress at work

  • Notice early when work is stacking up
  • Prioritise: safety → time-critical visits → then admin
  • Ask for help / escalate (PI, senior) — don’t absorb unsafe risk
  • Use lists / visit checklists; be honest about capacity
  • Breaks + proper handover when you can
  • Never rush consent or unsafe care to “clear the list”

One-liner: “Stress doesn’t disappear — I manage it so patients and the study stay safe.”

Prioritising complex trials & workload

  1. Safety / possible SAE — clinical help + PI
  2. Closing visit windows / timed samples / dosing visits
  3. Complex trial work — new consent, IMP visits, multi-step days
  4. Screening / recruitment
  5. Queries & paperwork (unless hard safety/data deadline)
  • Plan the week with team + PIs; protect slots for complex studies
  • Match tasks to competence / delegation log
  • Escalate early if capacity isn’t safe
  • Never rush consent or bend eligibility to hit numbers

One-liner: “I triage the portfolio — safety and windows first, then complex visits, then recruitment and admin.”

Underperforming junior / staff

  1. Act early; speak privately and calmly
  2. Use facts / examples — not personality labels
  3. Check cause: training, clarity, workload, wellbeing, competence
  4. Set clear expectations + simple support plan + review date
  5. Teach / supervise (Practice Supervisor mindset)
  6. If safety / GCP at risk → stop unsafe practice now
  7. Document fairly; escalate to senior / APDR process if no improvement

One-liner: “Support to improve, protect patients, escalate early if safety or performance doesn’t change.”

Colleague feels overwhelmed

  1. Listen without judgement; thank them for saying
  2. Look at the list together — prioritise (safety → windows → rest)
  3. Offer practical help: share / take tasks within competence
  4. Protect patients — nothing unsafe left hanging
  5. Check wellbeing; signpost senior / OH / Trust support if needed
  6. If workload isn’t safe → escalate capacity to senior
  7. Follow up later — “How are you now?”

One-liner: “Listen, prioritise together, help practically, and escalate if the workload isn’t safe.”

Low morale / motivate the team

  • Acknowledge the challenge honestly — don’t fake “everything’s fine”
  • Stay calm and visible; set clear priorities for today
  • Share the load; don’t leave people alone with impossible lists
  • Notice and thank people — small wins matter
  • Keep purpose in view: patients + safe, quality research
  • Escalate real blockers (capacity, process) to senior / PI
  • Check wellbeing; signpost support if needed

One-liner: “Acknowledge, support, clear priorities, escalate blockers — motivation from being heard, not empty slogans.”

Keeping up to date in research

  • Keep GCP + Trust research training / SOP updates current
  • Learn each study via SIV, protocol, amendments, PIS, sponsor emails
  • Learn from PI, senior research nurses, MDT, team meetings
  • Use NIHR / specialty updates relevant to the portfolio
  • For onc/haem: tumour-site learning + SACT pathway as you train
  • Ask early when something is outside your knowledge

One-liner: “I stay current through GCP, SIVs/protocols, the PI and team, and NIHR/specialty updates — and I ask when I’m unsure.”

Professional networking

  • Purpose: better patient access and safer study delivery — not show
  • Day to day: MDT, clinics, wards, day unit, CNS, PIs, research nurses
  • Cross-team: Hub / other specialties when covering
  • Learning events: Trust / NIHR / specialty sessions
  • Professional LinkedIn — careful and factual
  • Example: moved Hub → Cardiology to help; would build onc/haem links the same way

One-liner: “I network to build One Team relationships that help patients into research safely.”

Team member arrives late

  1. Cover patients / visits first — nothing unsafe left hanging
  2. Speak privately when they arrive — calm, not shaming
  3. Stick to facts (expected vs actual time)
  4. Listen — one-off vs pattern; genuine barriers?
  5. Re-state expectations + why (visit windows, fairness)
  6. Support if real issue; agree a simple plan
  7. If pattern / safety risk → escalate to senior / Trust process

One-liner: “Keep the service safe first, then address lateness privately, fairly, and escalate if it becomes a pattern.”

Colleague — repeated mistakes

  1. Safety / GCP first — stop unsafe practice; fix with PI if needed
  2. Private chat — facts / examples, not public blame
  3. Check causes: training, delegation log, clarity, workload, systems
  4. Support + supervised practice + clear “must improve by…”
  5. Document fairly
  6. If repeats after support → escalate to senior / performance process

Responsibility: individual works within competence; Band 6 supports, sets standards, escalates — does not ignore repeats.

One-liner: “Stop anything unsafe, support to improve, escalate if mistakes keep happening — looking away isn’t responsible.”

Organising tasks under high workload

  1. Get everything on a list (don’t keep it only in your head)
  2. Triage: safety/SAE → visit windows → complex visits → screening → admin
  3. Use diary / visit planner; protect time-critical slots
  4. Batch similar jobs where helpful (calls, queries)
  5. Match tasks to team competence
  6. Say early what’s at risk; escalate before windows are missed
  7. Same-day documentation where possible — stops snowballing

One-liner: “List it, triage it, plan it, escalate early — same habit as night in charge.”

Do not say

  • Made-up recruitment numbers
  • “I can give chemo / SACT already”
  • “I run the study” sounding like you are the PI (say lead local delivery)
  • “I’ve never done research / trials”
  • Promising a date you’ll be chemo competent
  • Criticising current team / specialty

Questions to ask them

  • What does the current onc/haem portfolio look like?
  • What SACT / chemo competence is expected in the first 6–12 months?
  • How is line management / APDR set up?
  • How do you balance specialty work with Hub / IOW cover?
  • What does good look like at 3 months and 12 months?
