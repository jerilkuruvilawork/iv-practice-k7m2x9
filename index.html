Simple speaking rules

  • Talk a bit slower than normal — like giving a calm handover.
  • Bold words: slow down a tiny bit there.
  • Stop for half a second after full stops.
  • On hard honesty bits: softer voice, not sorry, not angry.
  • On leadership bits: clear and steady — “this is what I do”.
  • At the end: finish the last line, then stop. Don’t add “yeah…” or “so…”.

Likely interview task — how to think

  • Patient safety first, then protocol / visit windows
  • Prioritise: clinical emergency / SAE → stop unsafe practice → time-critical visits → screening → admin queries
  • Consent pressure: voluntary, time, PIS, delegation log, never coerce, escalate to PI
  • SAE: help patient → tell PI → criteria → timelines → document
  • If unsure: say what you’d check and who you’d ask — don’t invent protocol rules

Mock task — prioritise these (15 min)

Write order 1–6, then say aloud. Full sheet: MOCK_TASK_PRIORITISATION.md

  1. A. Voicemail: participant admitted overnight with severe SOB on IMP study — please call back
  2. B. Visit window for Pt 014 closes today 17:00 (bloods, ECG, AE, eCRF) — slot 11:00
  3. C. Band 5 asks you to countersign consent — patient had no overnight PIS; consultant wants randomise today
  4. D. Sponsor queries (3 missing AE pages) — due end of tomorrow
  5. E. New screening referral — patient “keen and waiting now”
  6. F. Ward wants you to take protocol blood on SACT day unit now — you’re not signed off there / no SACT competence

Model order: A → C → B → F → E → D

  • A: safety + possible SAE → call / check safe → tell PI → timelines → document
  • C: do not countersign — stop, proper PIS/time, escalate if pressured
  • B: protect today’s window; escalate early if at risk
  • F: arrange competent person / safe place — don’t stretch into SACT area
  • E: screen properly or PIS + book back
  • D: after patients safe (deadline tomorrow)

One-liner: “Safety and valid consent first, then time-critical visits, escalate outside my competence, data queries last.”

Spine for all: safety → valid consent/GCP → protocol → PI/senior → document.

Consent — say these points

  • Capacity / understanding
  • Approved PIS + consent form only
  • On the delegation log for that study
  • What / why / risks / benefits / options
  • Voluntary + can withdraw; care continues either way
  • Time to decide; check understanding
  • Document; escalate to PI if unsure
  • Never pressure

SAE — order to say

  1. Patient safety / clinical help first
  2. Tell the PI straight away
  3. Is it serious? (hospital / life-threatening / etc. per protocol)
  4. Report within protocol / Trust timelines
  5. Document clearly
  6. Follow up and learn with the team

Do not say

  • Made-up recruitment numbers
  • “I can give chemo / SACT already”
  • “I run the study” sounding like you are the PI (say lead local delivery)
  • “I’ve never done research / trials”
  • Promising a date you’ll be chemo competent
  • Criticising current team / specialty

Questions to ask them

  • What does the current onc/haem portfolio look like?
  • What SACT / chemo competence is expected in the first 6–12 months?
  • How is line management / APDR set up?
  • How do you balance specialty work with Hub / IOW cover?
  • What does good look like at 3 months and 12 months?
